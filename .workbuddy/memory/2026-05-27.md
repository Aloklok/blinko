# 2026-05-27

## Blinko 本地 dev 启动排查
- **问题**: `bun run dev` 显示 localhost:1111 无法访问
- **根因**: 
  1. 端口 1111 需 Administrator 权限（EACCES）
  2. `ViteExpress.bind()` 需在 `app.listen()` 之前调用（改为 `http.createServer` → `bind` → `listen`）
  3. Express serve-static 错误处理器注入 `CSP: default-src 'none'` 阻止 Vite HMR
- **解决**:
  1. `.env` PORT 改为 2222
  2. `server/index.ts`：用 `http.createServer(app)` + `ViteExpress.bind(app, server)` + `server.listen()` 替代 `app.listen()`
  3. 开发模式添加中间件拦截 CSP 头
- **启动命令**: `cd D:\0project\blinko\server && bun --env-file ../.env --watch index.ts`
- **已知**: PgBouncer session mode pool_size=15, 多连接时 EMAXCONNSESSION, 离线任务(archive/rebuild)偶发失败但不影响核心服务
